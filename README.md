# Kicktrend

A modern blog platform built with Next.js 15, React 19, Tailwind CSS, Prisma, and TipTap.

## Getting Started

First, install dependencies:

```bash
npm install
```

Set up your `.env` file with your database and environment settings.

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
